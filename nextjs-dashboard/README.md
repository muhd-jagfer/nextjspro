# Next.js Dashboard

A dashboard application built by following the official **Next.js Learn Course** by Vercel.

The project is based on the **Dashboard App** from the course and was created to learn the basics of building a full-stack application with Next.js.

## Features

* User login
* Dashboard
* Customers
* Invoices
* Create, edit, and delete invoices
* Search and pagination
* Revenue data
* Authentication

## Technologies

* Next.js
* React
* TypeScript
* Tailwind CSS
* PostgreSQL
